# pod-mvp

**Purpose:**  
Print-on-demand Shopify brand MVP.

**Overview:**  
This project provides a minimal foundation for launching a focused print-on-demand Shopify brand in a single evergreen niche.

## Structure

- **ideas/**: Niche breakdown and slogan ideas.
- **prompts/**: AI image generation prompt templates.
- **copy/**: Product descriptions and email marketing drafts.
- **docs/**: Workflow documentation.

## Flow

1. **Niche Selection**: Define one evergreen niche with year-round demand.
2. **Design**: Prepare slogans and image prompts.
3. **Publish**: Write product descriptions and email drafts, follow workflow in docs.

## Human Input Required

- Niche definition and slogan ideas (`ideas/`)
- Image prompt creation (`prompts/`)
- Product details and emails (`copy/`)

## Instructions

1. Fill in niche and slogans in `ideas/`.
2. Add image prompts to `prompts/`.
3. Write product descriptions and emails in `copy/`.
4. Follow workflow steps in `docs/`.

**Keep branding minimal and focused. No API automation.**
