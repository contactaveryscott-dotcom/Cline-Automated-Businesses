# etsy-digital-mvp

**Purpose:**  
Etsy shop selling digital templates MVP.

**Overview:**  
This project provides a minimal foundation for launching an Etsy shop focused on a single family of digital products.

## Structure

- **products/**: Detailed template specifications.
- **listings/**: Title options, SEO descriptions, tags, FAQs.
- **docs/**: Instructions for template creation and Etsy listing.
- **scripts/**: CSV listing template generator (offline).

## Flow

1. **Product Design**: Specify one complete digital product family in `products/`.
2. **Listing Prep**: Draft titles, SEO, tags, FAQs in `listings/`.
3. **Template Creation**: Convert specs to Canva/Notion templates.
4. **Shop Listing**: Use docs for step-by-step Etsy listing instructions.

## Human Input Required

- Product specs (`products/`)
- Listing details (`listings/`)
- Manual template creation and Etsy upload

## Instructions

1. Fill in template specs in `products/`.
2. Draft listing content in `listings/`.
3. Follow instructions in `docs/` to create and list products.
4. Use scripts in `scripts/` for offline CSV generation if needed.

**No direct Etsy API usage. All tasks are manual or offline.**
