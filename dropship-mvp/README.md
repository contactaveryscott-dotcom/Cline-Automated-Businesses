# dropship-mvp

**Purpose:**  
One-product Shopify dropshipping business MVP.

**Overview:**  
This project provides a minimal, modular foundation for launching a single-product Shopify dropshipping store. All automation is offline and safe by default.

## Structure

- **copy/**: Product descriptions, FAQ, policies, email templates, ad hooks.
- **scripts/**: Order CSV processor, ad labeling script.
- **docs/**: Setup checklist, daily/weekly routines.

## Flow

1. **Idea → Store**: Define product, write descriptions, prepare store assets.
2. **Traffic**: Draft ad hooks, prepare email templates.
3. **Operations**: Use scripts to process orders and label ads.

## Human Input Required

- Product selection and details (`copy/`)
- Store setup tasks (`docs/`)
- Manual CSV export from Shopify for scripts

## Instructions

1. Fill in product info and policies in `copy/`.
2. Follow setup checklist in `docs/`.
3. Use scripts in `scripts/` for offline analysis.

**No Shopify API automation. All tasks are manual or offline.**
