# alerts-mvp

**Purpose:**  
Non-executing signal/alert system MVP.

**Overview:**  
This project provides a minimal, modular foundation for simulating alerts based on configurable rules and simulated data sources. No financial execution or real-time APIs.

## Structure

- **src/**: Minimal alert engine code.
- **config/**: Example alert configs.
- **docs/**: Instructions for adding new alerts.
- **alerts/**: Output logs.

## Flow

1. **Config Setup**: Define alert rules in `config/`.
2. **Simulation**: Use engine in `src/` to simulate data and trigger alerts.
3. **Logging**: Output alert logs to `alerts/`.

## Human Input Required

- Configuring alert rules (`config/`)
- Adding new alert types (`docs/`)
- Reviewing logs (`alerts/`)

## Instructions

1. Add or edit alert configs in `config/`.
2. Run simulation engine in `src/` (offline, manual).
3. Review output logs in `alerts/`.
4. Follow instructions in `docs/` to add new alerts.

**No financial execution or real-time APIs. All tasks are manual or offline.**
