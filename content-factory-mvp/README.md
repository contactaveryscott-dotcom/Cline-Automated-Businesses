# content-factory-mvp

**Purpose:**  
Short-form social content generator system MVP.

**Overview:**  
This project provides a minimal foundation for generating short-form social content in a chosen niche. All automation is offline and safe by default.

## Structure

- **niche/**: Niche definition (human input required).
- **scripts/**: Content generator scripts.
- **captions/**: Generated captions.
- **docs/**: Usage instructions and export format examples.

## Flow

1. **Niche Selection**: Define your target niche in `niche/`.
2. **Content Generation**: Use scripts in `scripts/` to generate video scripts and captions.
3. **Export**: Follow instructions in `docs/` for batch recording and structured export (CSV/JSON).

## Human Input Required

- Niche definition (`niche/`)
- Reviewing and editing generated scripts/captions

## Instructions

1. Add your niche definition to `niche/`.
2. Run scripts in `scripts/` to generate content.
3. Review and edit captions in `captions/`.
4. See `docs/` for usage and export instructions.

**Please define your niche in `niche/` before generating content.**
